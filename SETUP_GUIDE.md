# TypTalk - Setup Guide

## ✅ Vereisten:

**1. Karabiner-Elements** (MOET geïnstalleerd zijn!)
```bash
brew install --cask karabiner-elements
```

**Waarom Karabiner?**
- Detecteert Fn-toets (macOS blokkeert dit normaal)
- Heeft al permissies (Input Monitoring + Accessibility)
- TypTalk daemon heeft GEEN permissies meer nodig!
- Veel stabieler dan pynput

## 🚀 Quick Start:

```bash
cd ~/typtalk
./START_TYPTALK.sh
```

Nu werkt Fn-toets dictee! 🎉
